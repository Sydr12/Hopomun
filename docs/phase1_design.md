> 무협 배경 · 팀 육성 시뮬레이션 · 모바일 웹게임 (싱글 플레이, 추후 멀티 확장 고려)

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 팀 육성 시뮬레이션 (우마무스메 · 프린세스 메이커 계열) + 자동 턴제 전투 |
| 배경 | 무협 |
| 플랫폼 | 모바일 최적화 웹게임 (세로 화면) **[확정]** |
| 플레이 | 싱글 플레이 기반, 추후 멀티플레이 확장 고려 **[확정]** |
| 화풍 | 반실사풍 **[확정]** |
| 1페이즈 범위 | 팀원 4명 육성 → 2:2 대결 → 4:4 대결까지 **[확정]** |

**핵심 재미**
1. 무작위 후보 중 한 명을 골라 42턴 동안 키우는 육성
2. 수련 결과를 **심득**으로 보관하고 골라 끼우는 빌드 전략
3. 천성 · 세력 · 인연 · 9칸 배치를 조합하는 팀 편성

## 2. 전체 진행 (1페이즈) **[확정]**

```
① 1번 팀원 선발 (후보 3명 중 1명) → 수련
② 2번 팀원 선발 → 수련
③ ★ 1차 도전: 2:2 대결 (스토리 팀)
④ 3번 팀원 선발 → 수련
⑤ 4번 팀원 선발 → 수련
⑥ ★ 2차 도전: 4:4 대결 (스토리 팀)
→ 2페이즈로
```

- 2:2 · 4:4 대결 전에 팀원마다 **재수련** 가능.
- 대결에서 패배하면 **언제든 재도전** 가능 (재수련 후 재도전 포함).
- 후보에는 이미 팀에 있는 캐릭터는 나오지 않음. **[제안]**

## 3. 캐릭터

### 3.1 캐릭터 구성 **[확정]**
- 총 **32명**.
- 캐릭터마다 가진 것:

| 요소 | 설명 |
|---|---|
| 공격 계열 | 외공(공격1) 또는 내공(공격2) 중 하나 |
| 고유 스탯 | 외공 · 내공 · 호신 · 기혈 |
| 수련 초기 스탯 | 외공(수련) · 내공(수련) · 호신(수련) · 기혈(수련)의 시작값 |
| 신법(속도) | 캐릭터 고유 고정값 |
| 천성 | 고유 패시브 (§7) |
| 기본 액티브 | 고유 기본기 |
| 필살기 후보 2종 | 최종 시험에서 둘 중 하나 획득 |
| 세력 | 5개 중 하나 (§8) |
| 문파 | 설정용 소속 (예: 화산파 → 정파) |
| 인연 캐릭터 | 1명 (§8.3) |
| 고유 이벤트 | 3개 |

### 3.2 스탯 **[확정]**

| 역할 | 스탯 | 효과 |
|---|---|---|
| 공격1 | **외공**(外功) | 외공 계열 캐릭터의 공격력 |
| 공격2 | **내공**(內功) | 내공 계열 캐릭터의 공격력 |
| 방어 | **호신**(護身) | 받는 피해 감소 |
| 체력 | **기혈**(氣血) | 생명력 |
| 속도 | **신법**(身法) | 속도 게이지 충전량. 수련으로 오르지 않고 패시브 스킬로만 증가 |

- 계열과 다른 공격 스탯은 쓸모없음 (외공 계열에게 내공은 무의미).
- **최종 능력치 = 고유 스탯 + 적용 중인 심득의 수련 스탯** (스킬도 심득에서 옴).

## 4. 수련

### 4.1 구조 **[확정]**
- 수련은 항상 **수련 초기 스탯**에서 시작한다. 재수련도 이전 결과를 이어받지 않는다.
- 4개 지역을 차례로 돈다. 지역마다 **10턴**, 10턴째는 **지역 보스 1:1 결투**.
  - 승리 → 보상 받고 다음 지역 선택
  - 패배 → **즉시 수련 종료** (그때까지의 성장은 심득으로 저장됨)
- 41턴: 본진 귀환, 휴식 1턴
- 42턴: **최종 시험**
- 수련이 끝나면 결과가 **심득**이 된다 (§5).

### 4.2 지역 선택 **[확정]**

| 난이도 | 선택지 | 보스 보상 스킬 |
|---|---|---|
| 초급 | 2곳 중 1곳 | 액티브 1 |
| 중급 | 2곳 중 1곳 | 패시브 1 |
| 고급 | 3곳 중 1곳 | 액티브 2 |
| 최고급 | 3곳 중 1곳 | 패시브 2 |
| 최종 시험 | — | 필살기 (캐릭터 고유 2종 중 1) |

- 지역 선택 화면에 **주요 상승 능력치**를 표시한다. **[확정]**
- 지역마다 이벤트가 조금씩 다르다. **[확정]**

**지역 · 보스 · 성장 방향 [제안]**

| 난이도 | 지역 | 보스 | 주요 상승 | 연고 세력 |
|---|---|---|---|---|
| 초급 | 흑풍채 산채 | 흑풍채주 '철권' 마웅 | 외공 · 기혈 | 사파 |
| 초급 | 장강 나루터 | 수적 두목 '물귀신' 장삼 | 내공 · 호신 | 사파 |
| 중급 | 소림 나한당 | 십팔동인 | 외공 · 호신 | 정파 |
| 중급 | 사천 당문 독곡 | 당가 독수(毒手) 당표 | 내공 · 기혈 | 세가 |
| 고급 | 화산 낙안봉 | 매화검수 '낙화검' 청운자 | 외공 | 정파 |
| 고급 | 북해 빙궁 | 빙궁주 '설녀' 한소빙 | 내공 | 새외 |
| 고급 | 남만 독충림 | 오독교 만독노조 | 기혈 · 호신 (계열 무관) | 새외 |
| 최고급 | 검총(劍冢) | 검마(劍魔)의 잔영 | 외공 | 세가 |
| 최고급 | 십만대산 | 천마신교 좌호법 | 내공 | 마교 |
| 최고급 | 혈교 혈지(血池) | 혈마(血魔) | 기혈 · 호신 (계열 무관) | 마교 |

- 원칙: 난이도마다 **외공 선택지와 내공 선택지가 하나씩은** 있어서 어느 계열도 막히지 않는다.
- **지역 연고 [제안]**: 연고 세력 캐릭터는 그 지역 전용 이벤트 + 훈련 성장치 소폭 증가.

### 4.3 턴 행동 **[확정]**

한 턴에 **훈련 / 의뢰 / 휴식** 중 하나.

**훈련** — 외공 · 내공 · 호신 · 기혈 · 명상 중 선택
- 기력을 소모한다. 현재 기력이 낮을수록 **실패 확률**이 높다.
- 실패: 성공 수치의 **일부만** 성장, 기력은 동일 소모.
- 훈련마다 **레벨과 경험치**가 있다. 같은 훈련을 할수록 레벨이 오르고 상승치가 커진다. 실패해도 경험치는 동일하게 오른다.
- **명상**: 호신 · 기혈만 소폭 상승, 기력을 소모하지 않고 약간 회복.
- **크리티컬**: 확률적으로 성장치 증가.

**의뢰**
- 전투 또는 미니게임으로 퀘스트를 진행하고 **재화(보수)** 를 받는다.
- 기력을 소모하지 않는다. 기력이 부족해 훈련이 위험할 때의 대안.
- 1차 개발은 **전투 의뢰만** 만들고 미니게임은 이후 추가. **[제안]**
- 미니게임 후보 (모바일 터치): 암기 던지기(타이밍 탭), 진법 파훼(순서 기억), 화살 피하기(스와이프). **[제안]**

**휴식**
- 일반 휴식: 무료. 크리티컬 시 회복량 일부 증가.
- 고급 휴식: 비용 발생. 크리티컬 시 기력 전체 회복.

### 4.4 기력 **[확정]**
- 최대 **100** 고정. 훈련 · 이벤트로 소모, 휴식으로 회복.
- 수련 전용 자원 (전투와 무관).

### 4.5 상점 **[확정]**
- 수련 중 특정 턴마다 주기적으로 열린다.
- 무작위 상품 **3개** 중 **여러 개 구매 가능**. 재화로 **리롤** 가능.
- 상품:
  - 스탯 아이템 (능력치 일정량 상승), 기력 회복 아이템
  - **스킬 진화권**: 보유 스킬 하나를 즉시 1단계 진화. 낮은 확률(약 5%)로만 등장.
- 초급 보스 이전 상점은 스탯 · 기력 아이템만 나온다 (스킬 진화 없음).
- 필살기 획득(최종 시험) 이후에는 상점이 없다 → 필살기는 상점으로 강화 불가.
- 상점이 열리는 턴: 각 지역 **5턴째와 9턴째(보스 직전)** **[제안]**
- 재화 이름: **은자(銀子)** **[제안]**

### 4.6 이벤트 **[확정]**
- 특정 턴마다 확률적으로 발생.
- 이벤트가 발생하면 **이벤트 진행 + 그 턴의 행동**까지가 한 턴.
- **캐릭터 고유 이벤트**: 캐릭터마다 3종. 정해진 2개 턴에 확률 발생, 최대 2개.
- **인연 이벤트**: 인연 캐릭터의 이벤트. 정해진 2개 턴에 확률 발생, 최대 2개.
- 지역 이벤트: 지역마다 다름.

### 4.7 최종 시험 (42턴) **[확정]**
- 결과에 따라 보상(능력치 상승 또는 스킬)이 있다.
- **패배해도 심득은 완성**된다. 가치(점수)와 보상만 줄어든다.
- 시험 상대: **심마(心魔)** — 지금까지 수련한 자기 자신의 분신. 어떤 빌드든 난이도가 자동으로 맞춰진다. **[제안]**

## 5. 심득(心得)

### 5.1 개념 **[확정]**
- 수련 1회의 결과물. 수련 스탯 4종 + 획득 스킬을 담는다.
- **개인용**: 만든 캐릭터만 사용.
- 캐릭터당 **5개 보관**.
- 보관된 심득 중 **하나를 선택해 적용** → 최종 능력치 = 고유 스탯 + 심득 수련 스탯, 스킬도 심득의 것으로.
- 스킬 발동 우선순위 설정도 심득에 함께 저장된다 (§6.4).

### 5.2 이름 **[확정]**
- **최고급 지역 + 고급 지역** 이름 조합: 예) 혈지빙궁 심득, 검총독충 심득, 대산낙안 심득
- 최고급/고급에 도달하기 전에 수련이 끝난 경우: 도달한 가장 높은 두 지역으로 짓는다. 예) 나한흑풍 심득 **[제안]**

### 5.3 가치 평가 **[확정]**
- 수련 기간의 모든 성장을 종합해 **점수와 등급**을 매긴다.
- 등급 이름: 범품(凡品) → 정품(精品) → 상품(上品) → 절품(絶品) → 신품(神品) **[제안]**

### 5.4 수련 종료 보상 **[확정]**
- 심득 등급에 따라 **추가 스탯 상승**.
- 확률적으로 **스킬 업그레이드**. 낮은 확률로 **필살기 업그레이드**(1→2단계)도 가능.

## 6. 스킬

### 6.1 구성 **[확정]**

| 슬롯 | 획득처 | 종류 |
|---|---|---|
| 천성 | 캐릭터 고유 | 패시브 (전투 슬롯에 표시 안 함) |
| 기본 액티브 | 캐릭터 고유 | 액티브 |
| 액티브1 | 초급 보스 | 액티브 |
| 패시브1 | 중급 보스 | 패시브 |
| 액티브2 | 고급 보스 | 액티브 |
| 패시브2 | 최고급 보스 | 패시브 |
| 필살기 | 최종 시험 (고유 2종 중 1) | 액티브 |

- 총 **7개**(천성 포함). 전투 **액티브 슬롯은 4칸**: 기본 · 액티브1 · 액티브2 · 필살기.
- 액티브 · 패시브 모두 **외공 전용 / 내공 전용 / 공용**이 있다. 캐릭터 계열과 안 맞는 스킬은 후보로 나오지 않는다.
- 보스 보상: **후보 3개 중 1개** 선택.

### 6.2 등급 **[확정]**
- 일반 스킬: **S / A / B / C**. 획득 시 등장 확률 1 : 3 : 3 : 3.
- 진화: C → B → A → S 한 단계씩 (상점 진화권, 수련 종료 보상).
- 필살기: **1단계 / 2단계**. 2단계가 1단계보다 약 1.5배 위력.

### 6.3 쿨타임 **[확정]**
- 액티브 스킬마다 쿨타임이 있다.
- 필살기는 **초기 쿨타임**도 있다 (전투 시작 직후 사용 불가).

### 6.4 자동 발동 · 우선순위 **[확정]**
- 매 턴 직접 고르지 않는다. 전투 전에 **액티브 4칸의 발동 순서**를 정해 두면 자동 발동.
- 차례가 오면 순서대로 확인해 **쿨타임이 끝났고 조건을 만족하는 첫 스킬**을 쓴다.
- 기본 액티브는 쿨타임 0 → 아무것도 못 쓸 때의 기본 행동.

**발동 조건 (스킬당 1개, 선택) [제안]**

| 조건 | 예 |
|---|---|
| 항상 (기본) | 공격기 |
| 아군 중 기혈 ○% 이하 존재 | 회복, 보호막 |
| 대상 적 기혈 ○% 이하 | 처형기 |
| 한 줄에 적 2명 이상 | 관통, 열 공격 |
| 전투 ○턴 이후 | 버프 아껴 쓰기 |
| 아군 CC 상태 | 청심결 |

- 스킬마다 추천 조건이 기본 입력되어 있어 손대지 않아도 무난하게 동작.

### 6.5 스킬 태그 **[제안]**
- 모든 스킬에 태그: 반격, 중독, 다단, 회피, 보호, 호신, 도발, 회복, 강화, 약화, 연환, 혈공, 처형, 선공, 면역, 빙결 등.
- 천성과 같은 태그 스킬은 보스 보상 후보로 **2배 확률**로 등장하고, 사용 시 천성 **공명 효과**가 붙는다 (§7).

## 7. 천성(天性) **[제안 · 내용 다듬음]**

**공통 규칙**
1. 천성마다 태그가 하나 있다.
2. 같은 태그 스킬이 보스 보상 후보로 2배 확률 등장.
3. 같은 태그 스킬 사용 시 공명 효과.
4. 기본 액티브는 천성과 짝을 이루게 설계.

**16종 × 2명 = 32명**

| 태그 | 천성 | 기본 효과 | 공명 | 기본 액티브 예 |
|---|---|---|---|---|
| 반격 | 후발제인(後發制人) | 피격 시 25% 반격 | 반격 스킬 사용 후 1턴간 반격 100% | 반탄장 |
| 중독 | 독수(毒手) | 적중 시 중독 1중첩 | **다단히트** 스킬은 타격마다 중독 중첩 | 비침삼연 (독침 3연타) |
| 다단 | 쾌검(快劍) | 다단 스킬 타격 수 +1 | 다단 스킬 마지막 타격 치명 확정 | 일검삼영 |
| 회피 | 유수(流水) | 회피 +10%, 회피 시 게이지 +20% | 회피 스킬 후 다음 공격 +40% | 유운보 |
| 무적 | 금강불괴(金剛不壞) | **자기 턴 종료 시 기혈 30% 미만이면 1회 발동**, 자신의 다음 턴 종료까지 무적 **[확정]** | 보호막 흡수량 +30% | 금강호체 (보호막) |
| 호신 | 철벽(鐵壁) | 공격 피해에 호신의 50% 추가 | 호신 강화 스킬이 공격력도 강화 | 철산고 |
| 도발 | 호위(護衛) | 전투 시작 시 도발 1턴, **같은 행 뒤쪽 아군** 대신 맞기 20% | 도발 중 받는 피해 -30% | 사자후 (도발 + 적 게이지 감소) |
| 회복 | 의선(醫仙) | 회복량 +30% | 회복 시 상태이상 1개 해제 | 회춘수 |
| 강화 | 군사(軍師) | 아군 버프 지속 +1턴 | 버프 사용 시 아군 게이지 +15% | 고무 |
| 약화 | 점혈(點穴) | 적중 시 10% 기절 | 약화 효과 +1턴 | 점혈지 (적 게이지 감소) |
| 연환 | 연환(連環) | 행동마다 공격 +5% (최대 8중첩) | 연환 스킬은 2중첩 | 연환퇴 |
| 혈공 | 혈공(血功) | 기혈이 낮을수록 공격 증가 (최대 +50%) | 기혈 소모 스킬 위력 +30% | 혈조 |
| 처형 | 살수(殺手) | 기혈 30% 이하 적에게 피해 +40% | 처형 성공 시 쿨타임 초기화 | 암살 |
| 선공 | 발도(拔刀) | 전투 시작 게이지 +40% | 첫 공격 치명 확정 | 발도참 |
| 면역 | 부동심(不動心) | 모든 CC 면역, CC가 걸리려 할 때마다 공격 +8% (최대 5) | 면역 스킬 사용 시 아군 1명 1턴 CC 면역 | 명경지수 |
| 빙결 | 빙백(氷魄) | 적중 시 12% 빙결 | 빙결된 적 공격 시 치명 확정 | 한빙장 |

- 같은 천성의 두 캐릭터는 세력 · 계열 · 신법 · 필살기가 달라 다르게 플레이된다.
- 철벽 캐릭터도 외공/내공 계열을 그대로 가진다 (호신을 **추가**로 더하는 방식).

## 8. 세력 · 인연

### 8.1 세력 **[제안]**
- "출신" 대신 **세력 5개**로 버프를 묶고, 문파는 설정으로 둔다.
- 같은 세력 **2명 → 1단계, 4명 → 2단계** 버프. (4명 단일 세력 vs 2+2 조합의 선택)
- 적대 세력 페널티: **없음** **[확정]**

| 세력 | 인원 | 버프명 | 2명 | 4명 | 색 테마 |
|---|---|---|---|---|---|
| 정파(正派) | 7 | 협의(俠義) | 팀 호신 +10% | 아군이 처음 기혈 20% 이하가 될 때 팀 전체 보호막 | 청백 |
| 사파(邪派) | 6 | 약육강식 | 팀 공격 +10% | 적을 쓰러뜨린 아군 게이지 +50% | 흑갈 |
| 마교(魔敎) | 6 | 천마군림 | 팀 기혈 +10% | 가한 피해의 10% 흡혈 | 흑적 |
| 세가(世家) | 7 | 가전무공 | 팀 신법 +5% | 전투 시작 시 액티브 쿨타임 -1, 필살기 초기 쿨타임 -1 | 금색 |
| 새외(塞外) | 6 | 이역비술 | 상태이상 확률 +10% | 상태이상 지속 +1턴 | 은청 |

- 스토리 적 팀도 세력 기반으로 구성하고, 대결 전 상대 세력 · 천성을 공개한다.

### 8.2 지역 연고 **[제안]**
- §4.2 표의 연고 세력 캐릭터: 해당 지역 전용 이벤트 + 훈련 성장치 소폭 증가.

### 8.3 인연 **[확정 + 제안]**
- 캐릭터마다 인연 캐릭터가 있다. 한 팀에 배치하면 **인연 버프**(팀 전체 특정 능력치 상승). **[확정]**
- 32명 = 16쌍. 절반 정도는 **세력을 넘는 인연**으로 구성해 세력 버프와의 선택 고민을 만든다. **[제안]**

## 9. 전투

### 9.1 기본 **[확정]**
- **속도 게이지 턴제**: 신법만큼 게이지가 차고, 가득 찬 순서로 행동.
- 스킬은 **우선순위 자동 발동** (§6.4). 전투는 관전형 (1x/2x/4x 배속, 결과 바로 보기). **[제안]**
- 1:1 (보스, 의뢰, 최종 시험), 2:2, 4:4 모두 같은 규칙.

### 9.2 9칸 배치 **[확정]**

```
   [적 후열][적 중열][적 전열] | [아 전열][아 중열][아 후열]
1행    □       □       □     |    □       □       □
2행    □       □       □     |    □       □       □
3행    □       □       □     |    □       □       □
```

- 팀원(2명 또는 4명)을 9칸 중 원하는 곳에 배치.
- **기본 타격**: 적의 **가장 앞 열**을 먼저, 같은 열이면 **같은 행**을 우선. **[확정]**
- 스킬 사거리 유형 **[제안]**: 단일(앞열) / 관통(한 행 전체) / 열 공격(세로 3칸) / 저격(후열 직접) / 전체.

### 9.3 상태이상 (CC) **[제안]**

| CC | 효과 | 해제 |
|---|---|---|
| 기절(氣絶) | 다음 행동 1회 건너뜀 | 행동 차례 1회 경과 |
| 빙결(氷結) | 행동 불가 | 피격 시 해제, 그 공격 피해 +30% |
| 봉인(封印) | 액티브 사용 불가 (기본기만) | 2턴 |
| 둔화(鈍化) | 게이지 충전 -30% | 2턴 |
| 혼란(混亂) | 행동 시 50% 확률로 대상 무작위 (아군 포함) | 1턴 |
| 봉혈(封穴) | 회복 불가 | 3턴 |
| 도발(挑發) | 도발자만 공격 | 1~2턴 |
| 밀치기 / 당기기 | 적을 한 칸 뒤 / 앞으로 이동 | 즉시 |
| 중독 | 턴마다 피해, 중첩 | 지속 턴 |

그 외 효과: 보호막, 무적, 공격 강화 / 약화, 게이지 증감.

### 9.4 면역 **[제안]**
1. **공통**: 기절 · 빙결이 풀린 뒤 1턴간 같은 CC 면역 (CC 연쇄 방지). 보스는 행동 불가 CC가 둔화로 약화되어 적용.
2. **스킬**: 청심결(아군 CC 해제 + 2턴 면역, 액티브), 부동명왕(전투당 첫 CC 1회 무효, 패시브).
3. **천성**: 부동심 (§7).
4. **상성 면역**: 독수 천성 캐릭터 · 오독교 보스는 중독 면역.

### 9.5 수치 공식 **[미정]**
- 피해 · 방어 · 치명 · 게이지 공식과 성장 수치는 프로토타입(Python 버전)처럼 **시뮬레이션으로 밸런스를 맞춘 뒤** 확정.

## 11. 화면 흐름 (모바일 세로) **[제안]**

```
타이틀
 └ 본진 (팀 현황 · 진행 로드맵)
     ├ 팀원 선발 (후보 3명 카드)
```
