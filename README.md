# 호포문 (Hopomun)

무협 배경의 문파 경영 + 제자 육성 게임.

## 실행

```bash
pip install pygame
python -m hopomun.main      # GUI
python -m hopomun.cli_main  # 텍스트 모드
python -m pytest tests      # 테스트 (pytest 필요)
```

## 수련(육성) 모드

우마무스메 / 프린세스 메이커처럼 정해진 기간(36턴 = 3년) 동안 제자 한 명을 키웁니다.
문파 화면의 **수련** 아이콘에서 시작합니다.

- **수련 5종**: 외공 단련 · 경공 수련 · 점혈 수련 · 운기조식 · 참선. 같은 수련을 반복하면 숙련도(Lv1~5)가 올라 효율이 좋아집니다.
- **기력**: 수련하면 줄어듭니다. 50 미만이면 실패 확률이 생기고, 실패하면 능력치가 깎이거나 부상을 입습니다.
- **심경**: 최악~최상 5단계. 수련 효율에 ±20% 영향. 유람으로 올립니다.
- **휴식 / 유람 / 비무**: 기력 회복·부상 치료 / 심경 회복 / 강호 무인과 대련해 명성과 깨달음 획득.
- **무공**: 수련과 사건으로 얻은 깨달음을 소모해 익힙니다. 무기 전용 절기도 있습니다.
- **사건**: 매 턴 일정 확률로 선택지가 있는 사건(기연, 주화입마, 산적 출몰 등)이 일어납니다.
- **목표 대회**: 12턴 문파 비무대회, 24턴 성도 무림대회, 36턴 천하제일 비무대회.
- **엔딩**: 능력치·명성·대회 성적으로 등급(E~SS)과 칭호(천하제일인, 협객, 표사 …)가 정해지고, 결과는 문파원에게 그대로 남습니다.

주요 코드: `hopomun/systems/training.py`(육성 로직), `hopomun/systems/combat.py`(비무 전투),
`hopomun/data/training_data.py`(수련·사건·무공·대회 수치), `hopomun/gui/training_screens.py`(GUI).
