# 강호육성기 (웹)

기획서: [`../docs/phase1_design.md`](../docs/phase1_design.md)

## 현재 단계: 게임 코어 + 수련 화면(모바일)

| 폴더 | 내용 |
|---|---|
| `src/core/battle.ts` | 전투 엔진: 속도 게이지 턴제, 9칸 배치, 스킬 우선순위 자동 발동, CC · 면역, 천성 16종, 세력 · 인연 버프 |
| `src/core/training.ts` | 수련 상태 머신: 지역 4곳 × 10턴, 훈련/의뢰/휴식, 이벤트, 상점, 보스, 41턴 귀환, 42턴 최종 시험 |
| `src/core/shimdeuk.ts` | 심득: 이름 · 점수 · 등급 · 종료 보상 · 보관(캐릭터당 5개) |
| `src/core/combatants.ts` | 캐릭터 · 보스 · 적 · 심마 → 전투 입력 변환 |
| `src/core/rng.ts` | 시드 난수 (같은 입력 = 같은 결과) |
| `src/ui/` | 모바일 화면 (Preact): 타이틀 · 제자 선발 · 지역 선택 · 수련 · 이벤트 · 상점 · 전투 관전 · 심득 결과 · 보관함 |
| `src/data/` | 캐릭터(임시 6명) · 스킬 · 지역/보스 · 이벤트 · 상점 · 밸런스 수치 |
| `scripts/` | 밸런스 도구 (봇, 시뮬레이터, 진단, 보정) |

- 수련 상태(`TrainingState`)는 순수 JSON이라 그대로 저장/불러오기 가능하고, 난수 상태도 포함되어 있다.

## 명령

```bash
npm install
npm run dev         # 개발 서버 (휴대폰에서 보려면: npm run dev -- --host)
npm run build       # 배포용 빌드 (dist/)
npm test            # 테스트
npm run typecheck   # 타입 검사
npm run sim         # 봇 수련 시뮬레이션 (캐릭터별 보스 승률 · 등급 분포)
npm run diag        # 캐릭터 × 보스 승률 진단
npm run calib       # 보스 직전 평균 스탯 측정 (보스 기준 스탯 보정용)
```

## 밸런스 (봇, 캐릭터당 400회)

- **완주율 목표 70%**: 보스 4명을 모두 이기고 최종 시험에 도달하는 비율. 현재 전체 70% (캐릭터별 60~87%).
- 보스 승률(도달 기준): 초급 ~99% · 중급 ~97% · 고급 ~89% · 최고급 ~85% · 최종 시험 ~68%
- 심득 등급 분포: 범품 9% · 정품 27% · 상품 33% · 절품 23% · 신품 8%
- 보스 스탯은 "무난한 플레이의 보스 직전 평균 스탯(TIER_REFERENCE) × 보스 프로필 × 난이도 계수(BOSS_DIFFICULTY)"로 정한다.
  완주율은 BOSS_DIFFICULTY로 조절하고, 성장 수치를 바꾸면 `npm run calib` 로 기준을 다시 잰다.
- 봇은 무난한 플레이(공격 : 기혈 : 호신 = 1 : 0.7 : 0.5 비율로 훈련, 기력 45 미만이면 휴식)를 흉내 낸다.
  실제 플레이어가 더 잘하거나 못하면 체감 완주율은 달라질 수 있다.

## 구현하며 정한 세부 규칙 (기획서에 없던 부분)

- 최종 시험에서 져도 필살기는 얻는다. 이기면 수련 스탯 +40, 지면 +15 (보상 차이).
- 일러스트는 `public/art/` 에 넣고 `src/data/art.ts` 목록에 파일명을 추가하면 실루엣 대신 표시된다.
- `node scripts/bundle-single.mjs` 로 빌드를 파일 하나짜리 페이지로 묶을 수 있다 (미리보기 공유용).
- 상점 스킬 진화권은 보유 스킬 중 무작위 하나를 진화시킨다.
- CC가 풀린 뒤 면역은 없다. 면역은 천성(부동심) · 스킬(청심결, 부동명왕, 명경일권 등)로만 얻는다.
- 자기 턴에 스스로 건 버프(도발 등)는 다음 자기 턴 종료까지 유지된다.
- 지역 이벤트는 지역 3 · 7턴째, 캐릭터 고유 이벤트는 6 · 26턴, 인연 이벤트는 16 · 36턴에 확률 발생.
